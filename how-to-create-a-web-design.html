How to Create a Web Design

Creating a website design is easier when you follow a clear process. These 8 steps are the same process professional designers use to go from a blank page to a finished, responsive web page design.

5 min readGuide
Expert tipsBy our team
By Buddhika S Weerasekara5 min readUpdated 24 November 2026
Key takeaways
  • Define the goal and audience before designing anything.
  • Go from sitemap, to wireframe, to full design. Fix the structure first.
  • Design desktop (1440px) and mobile (390px) versions of every page.
  • Test speed, links, forms and real phones before launch.

1. Define the Goal and Audience

Every good web design starts with two questions: who is this website for, and what should visitors do? A restaurant wants table bookings, a shop wants online orders and a service company wants enquiries. Write down the main goal, the target customers and the key messages before you design anything.

It also helps to look at 3 to 5 competitor websites. Note what they do well, what is missing and how your website can be clearer, faster or more helpful.

2. Plan the Sitemap and Content

List all the pages the website needs, for example Home, Services, Portfolio, Packages, About and Contact, and how they connect. Then plan the content for each page: headings, text, images and calls to action. Designing with real content gives far better results than using placeholder text.

3. Sketch Wireframes

A wireframe is a simple black-and-white layout that shows where each element goes on the page, without colours or images. Sketch on paper or use Figma to quickly try different layouts for the header, hero section, content blocks and footer. Fix the structure first, then make it beautiful.

The Anatomy of a Good Home Page

Most effective home pages follow a similar structure from top to bottom:

  1. Header: logo, a short menu and a clear contact button.
  2. Hero section: a headline that says what you do, a short sub-heading and one main call to action.
  3. Trust bar: client logos, review stars or key numbers.
  4. Services or products: short cards that link to detailed pages.
  5. Proof: portfolio examples, case studies and testimonials.
  6. How it works: 3 or 4 simple steps that remove uncertainty.
  7. FAQ: answers to the questions customers ask most.
  8. Final call to action and footer: contact details, map, social links and important pages.

4. Choose Colours, Fonts and Style

Pick a colour palette of one main brand colour, one accent colour and neutral greys. Choose one or two readable fonts from Google Fonts, for example one for headings and one for body text. Collect a mood board of websites and images you like to keep the style consistent across every page.

5. Design the Web Page in Figma or Photoshop

Now turn your wireframe into a full-colour web page design. In Figma, create a desktop frame (1440px wide) and a mobile frame (390px wide), use a 12-column grid and build reusable components for buttons and cards.

If you prefer Photoshop, start a new document 1440px wide, add guides for a 12-column grid, use separate layer groups for each section and save colours and text styles in libraries. Photoshop is great for image-heavy designs, while Figma is better for collaboration and prototypes.

Whatever tool you use, name your layers and sections clearly. It saves hours when the design is handed to a developer.

How to Design a Web Page in Photoshop (Quick Method)

  1. Create a new document 1440px wide (the height can grow), RGB colour, 72 PPI.
  2. Add a 12-column grid with View > Guides > New Guide Layout (for example 1200px content width and 24px gutters).
  3. Create a layer group for each section: header, hero, services, testimonials, footer.
  4. Use shapes for buttons and cards, and keep text as live type layers.
  5. Save your brand colours as swatches and your text styles as character styles.
  6. Create a separate 390px-wide document for the mobile version.
  7. Export images with File > Export > Export As in WebP or JPG, and share the PSD with your developer.

6. Make It Responsive

Design how each section rearranges on tablets and phones: columns stack, images resize, text sizes adjust and the menu becomes a tap-friendly button. With most visitors on mobile, the phone version is often the most important design of all.

ItemRecommended size
Desktop design width1440px (content area about 1200px)
Tablet design width768px
Mobile design width390px
Body text16px to 18px
Buttons and tap targetsAt least 44px tall
Line lengthAbout 60 to 80 characters

7. Build and Test the Website

Turn the design into a working website with HTML, CSS and JavaScript or a CMS such as WordPress (see WordPress vs custom website). Then test everything: page speed on mobile, every link and form, different browsers, and real Android and iPhone devices. Check SEO basics such as page titles, meta descriptions, headings and image alt text.

8. Launch and Improve

Connect your domain, install an SSL certificate, submit the sitemap to Google Search Console and set up Google Analytics. After launch, watch how visitors use the site and keep improving the design and content based on real data.

Common Web Design Mistakes to Avoid

  • Too much text and no headings: visitors scan pages, so break text into short sections.
  • Huge, uncompressed images: they make pages slow, especially on mobile data.
  • Many competing buttons: give each section one clear call to action.
  • Low contrast text: light grey on white is hard to read outdoors on a phone.
  • Hidden contact details: phone, WhatsApp and location should be easy to find.
  • Designing only for desktop: always design the mobile version too.

Frequently Asked Questions

What is the best software to create a web design?

Figma is the most popular tool for creating web designs today because it is free to start, works in the browser and makes prototyping and teamwork easy. Adobe Photoshop and Adobe XD are also widely used.

How do I design a web page in Photoshop?

Create a 1440px-wide document, add guides for a 12-column grid, design each section in its own layer group, use consistent text and colour styles, then export images and hand the design over for development.

Can I create a website design without coding?

Yes. You can design in Figma without code and build with no-code platforms or WordPress page builders, although coding skills give you more control over speed and SEO.

What size should a web page design be?

Design desktop pages at 1440px wide with a content area of about 1200px, and design mobile pages at about 390px wide. The height depends on your content.

How long does it take to create a web design?

A simple 5-page website design usually takes 1 to 2 weeks. Larger business websites and online stores can take 3 to 6 weeks, including revisions and development.
